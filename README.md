# LabSafe 

Aplicação para treinamento em segurança nos laboratórios.

## Objetivo
Desenvolver um sistema de treinamento em segurança nos laboratórios, reforçando o conhecimento do aluno e verificar se ele realmente tem a capacidade de entrar em laboratórios.

## Tecnologias utilizadas

- Node.js
- Fastify 
- TypeScript

## Como executar o projeto

### 1. Clonar o repositório
```bash
git clone https://github.com/goncalvesjv2/labsafe-backend
```

### 2. Acessar o projeto
```bash
cd gestao-reagentes-backend
```

### 3. Abrir no VS Code
```bash
code .
```

### 4. Configurar arquivo .env

Criar arquivo:
```txt
.env
```

Dentro do env, digite:
```env
PORT={número}
```

Esse número, você que escolhe, não tem necessidade de digitar um número longo, escolha um de unidade milhar.

### 5. Instalar as dependências
```bash
npm install
```

### 6. Rode o servidor 
```bash
npm run start
```
